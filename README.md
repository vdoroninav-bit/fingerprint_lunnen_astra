# Сканер отпечатков Lunnen LL4FA в Astra Linux

Адаптированный DEB-пакет проприетарного драйвера FocalTech для встроенного сканера **2808:c652**. Позволяет регистрировать и проверять отпечатки через `fprintd`, а также использовать их в PAM, например для `sudo`.

## Проверенная модель и система

| Параметр | Проверенная конфигурация |
|---|---|
| Производитель | **Lunnen** |
| Модель из DMI (`product_name`) | **LL4FA** |
| Сканер | FocalTech Fingerprint Device, USB **2808:c652** |
| ОС | Astra Linux; `/etc/os-release`: `VERSION_ID=12.8_x86-64`, `VARIANT_ID=ce` |
| Подключённый репозиторий | Astra 1.8 x86-64, frozen 1.8.3 |
| Ядро | `6.12.34-1-generic` |
| Архитектура | amd64 / x86-64 |
| fprintd / libpam-fprintd | `1.94.2-2+ci4+b2` |
| libgusb2 | `0.3.10-1+b3` |

Полный торговый артикул ноутбука не определён: подтверждённая модель — именно **Lunnen LL4FA по DMI**. Работа на всех ноутбуках Lunnen или всех вариантах LL4FA не заявляется: сначала сверяйте USB ID.

```bash
cat /sys/class/dmi/id/sys_vendor /sys/class/dmi/id/product_name
lsusb -d 2808:c652
```

## Результаты испытаний

- Устройство обнаруживается `fprintd`.
- Регистрация правого указательного пальца завершилась `enroll-completed`.
- Две последовательные проверки завершились `verify-match`.
- Подтверждение `sudo` отпечатком без ввода пароля проверено пользователем.
- **Графический вход и разблокировка Fly на этой конфигурации пока не работают; причина не установлена.** Установка пакета не гарантирует их исправление.
- `su`, текстовый вход и Polkit используют общую конфигурацию PAM, но успешные испытания этих сценариев пока не подтверждены.

## Установка и проверка

Скачайте репозиторий или клонируйте его, затем в его каталоге:

```bash
sha256sum -c SHA256SUMS
sudo apt-get install ./libfprint-2-2_1.94.5+tod1.astra1_amd64.deb fprintd
sudo apt-mark hold libfprint-2-2
sudo systemctl restart fprintd
fprintd-enroll -f right-index-finger
fprintd-verify -f right-index-finger
```

Прикладывайте палец, убирая его между считываниями. Ожидаемые результаты: `enroll-completed`, затем `verify-match`. Запрос повторного считывания не равен окончательному отказу. Дополнительно проверьте незарегистрированный палец — ожидается `verify-no-match`.

Для подключения к PAM после успешной проверки:

```bash
sudo apt install libpam-fprintd
sudo pam-auth-update
```

Включите **Fingerprint authentication**, сохранив **Unix authentication** для входа по паролю. Используйте непустой пароль. Тест `sudo` из обычного терминала:

```bash
sudo -k
sudo -v
```

Приложите зарегистрированный палец. При успехе `sudo -v` завершается без вывода. При настройке PAM отпечаток используется как альтернатива паролю, а не как обязательный второй фактор.

Пакет закрепляется через `apt-mark hold`, чтобы обновление не заменило его стандартной библиотекой без этого драйвера. Закрепление нужно учитывать при обслуживании системы.

## Что изменено в пакете

Исходник: [ryenyuku/libfprint-ft9201, выпуск 1.94.4_20250219](https://github.com/ryenyuku/libfprint-ft9201/releases/tag/1.94.4_20250219).

SHA256 исходного DEB:

```text
fe8c5ebb685718075e1fc04f10378c001e149b80c283d2891318a50e0588401a
```

- Версия пакета заменена на `1:1.94.5+tod1.astra1` для удовлетворения зависимости `fprintd` из репозитория Astra. **Код остаётся из vendor-сборки 1.94.4; это не обновление исходного кода до 1.94.5.**
- Добавлена явная зависимость `libgudev-1.0-0`.
- Широкие правила udev для FocalTech заменены точным правилом `2808:c652` с `power/control=on`.
- `postinst` обновляет правила udev, применяет их к целевому сенсору и вызывает `ldconfig`.
- Пересчитаны `md5sums`.
- Библиотека драйвера не изменялась: таблица устройств уже содержит `2808:c652`.

Проверены загрузка библиотеки с библиотеками установленной Astra и пробная установка APT без конфликтов/удаления пакетов. Испытания оборудования выполнены пользователем в обычном терминале ноутбука.

## Откат

Если включали отпечаток в PAM, сначала отключите **Fingerprint authentication** через `sudo pam-auth-update`, сохранив Unix authentication.

```bash
sudo apt-mark unhold libfprint-2-2
sudo apt-get install --allow-downgrades libfprint-2-2=1:1.94.5-1+ci3
sudo systemctl restart fprintd
```

Версия выше соответствует репозиторию на момент проверки. Если она недоступна, выберите штатную версию через `apt-cache policy libfprint-2-2`. Откат библиотеки не удаляет зарегистрированные отпечатки; управлять ими можно через `fprintd-delete`.

## Происхождение и лицензирование

Это сторонняя адаптация, не официальный драйвер Astra или Lunnen. Бинарный драйвер FocalTech проприетарный; лицензия репозитория не распространяет MIT-лицензию на сторонние бинарные компоненты. Сведения о правах исходного пакета сохранены внутри DEB в `/usr/share/doc/libfprint-2-2/copyright`.
